# غصون زهران - العمل الميداني (Android)

تطبيق أندرويد شخصي للعمل الميداني، يعمل **بدون إنترنت بالكامل**. لا يحتاج Play Store،
ولا يوجد فيه أي اتصال بخادم أو مزامنة تلقائية: البيانات تُحفظ في قاعدة SQLite محلية داخل
مساحة التطبيق، ولا تغادر الهاتف إلا عبر **ملف نقل** يُنشئه المستخدم بنفسه ويرسله يدوياً.

## ما الذي يفعله التطبيق

- تسجيل الأسر والمستفيدين أثناء الزيارات.
- البحث الاجتماعي الكامل (الدخل، السكن، الصحة، الأطفال، الأيتام، الاحتياجات، التوصية).
- الزيارات الميدانية والمساعدات.
- إرفاق الصور بالسجلات (تُنسخ داخل مساحة التطبيق الخاصة).
- قفل بالتطبيق برمز PIN مع تأخير تصاعدي بعد المحاولات الخاطئة.
- تصدير ملف `.gztransfer` واستيراد قائمة الأسر من الكمبيوتر.

## طريقة النقل بين الهاتف والكمبيوتر

1. من الكمبيوتر: شاشة **النقل من الهاتف** ← "تصدير بيانات الأسر إلى الهاتف" ← انقل الملف
   إلى الهاتف ← من التطبيق: **النقل** ← "اختيار ملف نقل".
2. من الهاتف بعد العمل الميداني: **النقل** ← "تصدير السجلات الجديدة والمعدلة" ← شارك الملف
   (كابل، واتساب، بريد) ← من الكمبيوتر: **النقل من الهاتف** ← "اختيار ملف النقل" ← راجع
   المعاينة ← "اعتماد الاستيراد".

الاستيراد على الكمبيوتر لا يعدّل قاعدة البيانات قبل الاعتماد، ولا يقبل نفس الملف مرتين،
ولا يستبدل بيانات أحدث موجودة على الكمبيوتر.

## بناء ملف APK

مطلوب: Node.js 18+، وJava JDK 17، وAndroid SDK (أو حساب Expo لبناء سحابي).

```bash
cd mobile
npm install
```

### الخيار الأول: بناء محلي مباشر (بدون حساب)

```bash
npx expo prebuild --platform android --clean
cd android
./gradlew assembleRelease
```

الناتج:
`mobile/android/app/build/outputs/apk/release/app-release.apk`
أعد تسميته إلى `GhsoonZahran-Mobile.apk` وانقله إلى الهاتف وثبّته
(يتطلب تفعيل "تثبيت التطبيقات من مصادر غير معروفة").

> ملاحظة: `assembleRelease` بدون مفتاح توقيع يستخدم مفتاح التصحيح الافتراضي، وهو كافٍ
> لتطبيق شخصي. لتوقيعه بمفتاحك الخاص أنشئ keystore وأضفه في
> `android/app/build.gradle`.

### الخيار الثاني: EAS Build

```bash
npx eas-cli build --platform android --profile apk
```

الملف `eas.json` معدّ مسبقاً لإنتاج APK (وليس AAB).

## التشغيل أثناء التطوير

```bash
npm start          # ثم امسح رمز QR بتطبيق Expo Go
npm run typecheck  # فحص الأنواع
```

## بنية المشروع

```
src/
  transfer-format.ts     نسخة مطابقة من صيغة النقل في تطبيق الكمبيوتر
  db/schema.ts           جداول SQLite المحلية (أسماء الأعمدة مطابقة للكمبيوتر)
  db/client.ts           فتح القاعدة، المعرّفات، معرّف الجهاز
  db/repository.ts       عمليات القراءة والكتابة
  services/transfer.ts   إنشاء وقراءة ملفات .gztransfer
  services/attachments.ts نسخ الصور داخل مساحة التطبيق
  services/lock.ts       رمز الدخول
  screens/               الشاشات
  ui/                    المكونات المشتركة
```

`src/transfer-format.ts` **نسخة حرفية** من `src/lib/transfer-format.ts` في تطبيق
الكمبيوتر. أي تعديل يجب أن يُنسخ إلى الملفين معاً — يوجد اختبار في تطبيق الكمبيوتر
(`tests/transfer-format-sync.test.ts`) يفشل إذا اختلفا.
